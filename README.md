## 🌟 核心藝術特色與技術突破

1. **正宗查爾斯·舒茲漫畫輪廓（Charles M. Schulz Authentic Form）**：
   - 拋棄失真的純幾何或抽象簡筆畫，全量 7 組造型均直接對齊查爾斯·舒茲官方漫畫原作精確輪廓！
   - 每一個史奴比姿勢皆由 **480 顆高精度文字粒子** 緊密排列而成，嚴格維持 **160 個「閻」**、**160 個「姿」**、**160 個「桂」** 完美均衡循環。
   - 經典特徵精準還原：圓潤下垂的大黑耳、長條圓弧鼻吻、小巧圓鼻頭、標誌性鮮紅項圈、微凸的可愛肚腩與小短腿，保證一眼辨認出正宗史奴比神韻！
   - 在任何形變與姿勢切換過程中，文字粒子永不消失，而是化作漩渦風暴與彈簧引力，於時空中優雅重組。

2. **慢速演進動畫與底部無遮擋控制台（Non-Obstructive Evolution Dock）**：
   - 徹底重構介面排版，將演進時間軸滑桿與速度調控移至底部操控塢（Bottom Dock），並將標題整合至頂部微型抬頭，**釋放中央 100% 畫布視野**，動畫完全不被任何進度條阻擋。
   - 具備專屬「演進控制台」，展示文字粒子如何從四散宇宙的混亂狀態，沿著優美弧線慢速匯聚、組裝成高精度插圖。
   - 採用**分層階梯式組裝邏輯**：骨架線條最先浮現（0.0~0.15），隨後五官與經典特徵精準鑲嵌（0.14~0.28），最後外在配件與場景完美就位（0.26~0.42），宛如無形畫家在螢幕上一筆一劃繪出史奴比。
   - 支援 **時間軸滑桿自由前後拖曳**、**播放/暫停**、**重新演進**，以及 **0.5x（慢速細賞）/ 1.0x（流暢）/ 2.0x（快速）** 速度切換。

3. **收錄 7 大正宗經典史奴比可愛造型**：
   - 🏠 **#1 趴臥狗屋白日夢 (Daydreaming on the Doghouse)**：正宗水平趴臥紅色狗屋頂，舒茲招牌悠閒神情。
   - 😎 **#2 墨鏡酷哥喬酷兒 (Joe Cool with Sunglasses)**：深黑墨鏡、反戴鴨舌帽與酷帥神情。
   - 💃 **#3 快樂開懷跳躍舞 (The Joyful Happy Dance)**：雙手敞開、雙足凌空躍起的歡樂神態。
   - 🛩️ **#4 一戰王牌飛行員 (World War I Flying Ace)**：經典飛行皮帽與迎風飄揚的標誌鮮紅長圍巾。
   - ❤️ **#5 暖暖擁抱大愛心 (Love & Big Warm Hug)**：史奴比與糊塗塌客同心相擁，溫暖人心的大愛心輪廓。
   - 🌳 **#6 開心擁抱大自然 (Snoopy in Nature)**：舒茲標誌站姿、迎風展臂擁抱大自然的開朗神采。
   - 📖 **#7 好友相伴悄悄話 (Whispering with Woodstock)**：史奴比坐在狗屋頂上靜心閱讀，糊塗塌客在上方歡欣共處。

3. **四大前衛藝術風格濾鏡（Thematic Art Directions）**：
   - 📰 **經典花生報紙 (Vintage Sunday Comic)**：舒茲溫暖米黃報紙紋理、孔版半色調網點與經典炭墨黑。
   - 🌌 **賽博深空霓虹 (Midnight Cyberpunk Glow)**：純黑曜石深空、極光青藍、電紫流光與光暈呼吸動效。
   - 🎨 **日系雙色孔版 (Risograph Duotone)**：螢光桃紅與深海靛藍對比疊印、復古印刷套印錯位趣味。
   - 📜 **宮廷金箔水墨 (Imperial Gold & Calligraphic Ink)**：仿宣紙水墨邊緣暈染、朱砂正紅與璀璨金箔碎屑。

4. **手機端原生流暢手勢與互動**：
   - 👆 **指尖風動與磁力擾動**：手指滑過螢幕時，文字粒子如同被秋風捲起的落葉般翻滾飄散，鬆手後彈力回位。
   - 📱 **陀螺儀重力傾斜 (Device Tilt)**：拿起手機傾斜角度，史奴比與文字粒子將即時感應真實重力偏移。
   - 💫 **雙擊時空炸裂與重組 (Quantum Scatter)**：解構史奴比成為無垠宇宙文字雲，再次觸碰震撼回歸。
   - 🖌️ **文字筆刷模式 (Calligraphy Sparkle Wand)**：開啟筆刷後，在螢幕任意滑動即可繪出飄落的閻姿桂字雨。
   - 🎵 **純 Web Audio 程序化合成配樂**：無外部音檔相依性，切換時即時合成五聲音階甘美朗清脆和弦。
   - 📸 **一鍵輸出 1080×1920 高畫質拍立得藝術桌布**：內建「閻姿桂 印」專屬鈐印與哲理箴言，可直接存為手機鎖定桌布。

## 🚀 本地執行方式

本專案採用純原生技術（HTML5 Canvas 2D + ES6 + Web Audio API），無須安裝任何肥大框架或第三方相依套件：

1. 直接以現代瀏覽器（Chrome, Safari, Edge, Firefox）開啟 `index.html`。
2. 或使用任意輕量級靜態網頁伺服器：
   ```bash
   python -m http.server 8000
   ```
   瀏覽器造訪 `http://localhost:8000` 即可暢快體驗！
