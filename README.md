## 🌟 核心藝術特色與技術突破

1. **嚴謹文字動力學（Kinetic Typography）**：
   - 每一個史奴比姿勢皆由 **420 顆文字粒子** 緊密排列而成，嚴格維持 **140 個「閻」**、**140 個「姿」**、**140 個「桂」** 完美均衡循環。
   - 在任何形變與姿勢切換過程中，文字粒子永不消失，而是化作漩渦風暴與彈簧引力，於時空中優雅重組。

2. **收錄 7 大經典史奴比可愛造型**：
   - 🏠 **#1 趴臥狗屋白日夢 (Daydreaming on the Doghouse)**：經典紅色狗屋頂、白日夢氣泡與好友糊塗塌客。
   - 😎 **#2 墨鏡酷哥喬酷兒 (Joe Cool with Sunglasses)**：帥氣深黑墨鏡、紅色大學毛衣與靠牆瀟灑姿態。
   - 💃 **#3 快樂開懷踢踏舞 (The Joyful Happy Dance)**：雙耳逆風高飛、仰天大笑踢腿與旋轉音符。
   - 🛩️ **#4 一戰王牌飛行員 (World War I Flying Ace)**：飛行皮帽、圓形風鏡、迎風狂飆的鮮紅圍巾與雲海。
   - ❤️ **#5 暖暖擁抱大愛心 (Love & Big Warm Hug)**：雙手緊抱碩大立體愛心、靦腆腮紅與升空愛心氣泡。
   - 🐥 **#6 與糊塗塌客悄悄話 (Snoopy & Woodstock Whispers)**：史奴比溫柔坐立，糊塗塌客駐足鼻尖甜蜜合唱。
   - ⛳ **#7 高爾夫優雅揮桿 (Championship Golfer Ace)**：遮陽球帽、揮桿收桿動態與劃破天際的白色高爾夫球拋物線。

3. **四大前衛藝術風格濾鏡（Thematic Art Directions）**：
   - 📰 **經典花生報紙 (Vintage Sunday Comic)**：舒茲溫暖米黃報紙紋理、孔版半色調網點與經典炭墨黑。
   - 🌌 **賽博深空霓虹 (Midnight Cyberpunk Glow)**：純黑曜石深空、極光青藍、電紫流光與光暈呼吸動效。
   - 🎨 **日系雙色孔版 (Risograph Duotone)**：螢光桃紅與深海靛藍對比疊印、復古印刷套印錯位趣味。
   - 📜 **宮廷金箔水墨 (Imperial Gold & Calligraphic Ink)**：仿宣紙水墨邊緣暈染、朱砂正紅與璀璨金箔碎屑。

4. **手機端原生流暢手勢與互動**：
   - 👆 **指尖風動與磁力擾動**：手指滑過螢幕時，文字粒子如同被秋風捲起的落葉般翻滾飄散，鬆手後彈力回位。
   - 📱 **陀螺儀重力傾斜 (Device Tilt)**：拿起手機傾斜角度，史奴比與文字粒子將即時感應真實重力偏移。
   - 💫 **雙擊時空炸裂與重組 (Quantum Scatter)**：解構史奴比成為無垠宇宙文字雲，再次觸碰震撼回歸。
   - 🖌️ **文字筆刷模式 (Calligraphy Sparkle Wand)**：開啟筆刷後，在螢幕任意滑動即可繪出飄落的閻姿桂字雨。
   - 🎵 **純 Web Audio 程序化合成配樂**：無外部音檔相依性，切換時即時合成五聲音階甘美朗清脆和弦。
   - 📸 **一鍵輸出 1080×1920 高畫質拍立得藝術桌布**：內建「閻姿桂 印」專屬鈐印與哲理箴言，可直接存為手機鎖定桌布。

## 🚀 本地執行方式

本專案採用純原生技術（HTML5 Canvas 2D + ES6 + Web Audio API），無須安裝任何肥大框架或第三方相依套件：

1. 直接以現代瀏覽器（Chrome, Safari, Edge, Firefox）開啟 `index.html`。
2. 或使用任意輕量級靜態網頁伺服器：
   ```bash
   python -m http.server 8000
   ```
   瀏覽器造訪 `http://localhost:8000` 即可暢快體驗！
